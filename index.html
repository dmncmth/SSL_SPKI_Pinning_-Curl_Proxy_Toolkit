What is SPKI Pinning?

        

          Subject Public Key Info (SPKI) pinning binds connections to the cryptographic public key itself instead of the entire certificate. When renewing certificates, keeping the same private key preserves the pin.
        

      


      

        
Why Squid Fails the Pin

        

          Squid SSL-Bump intercepts traffic by generating a dynamic certificate on-the-fly signed by squidCA.crt. Even though Curl trusts the CA, the dynamically generated key does not match the pinned public key hash.
        

      


      

        
Expected Curl Exit Code

        

          When pinning is violated, Curl terminates handshake with curl: (90) SSL: public key does not match pinned public key!, protecting clients from unauthorized interception.
